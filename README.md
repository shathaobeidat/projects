
#  Portfolio

A responsive, modern personal portfolio website built with HTML5 and CSS3 to showcase full-stack projects, core technical skills, and professional contact details.

---

# Features

* **Responsive Layout:** Optimized across desktop, tablet, and mobile devices using CSS Grid, Flexbox, and Media Queries.
* **Modern Blue Aesthetics:** Clean light blue palette featuring gradient headings, sticky header navigation, and custom dynamic styling.
* **Keyframes Animations:** 
  * Floating card animation for key technologies (`@keyframes floatingTech`).
  * Fade-in slide-up animation for hero avatar (`@keyframes fadeInSlideUp`).
* **Featured Projects Showcase:** Cards display recent projects like *Skill-bridge Platform* and *Talentia* with hover effects.
* **Interactive Contact Section:** Integrated input form alongside actionable contact info (Email, Phone, Location, and LinkedIn).

---

##  Tech Stack & Tools

* **Frontend:** HTML5, CSS3 (CSS Variables, Flexbox, CSS Grid)
* **Icons:** Embedded SVG icons (Lucide / Feather Icons style) & Devicon CDN
* **Typography:** Inter & Orbitron (Google Fonts)
